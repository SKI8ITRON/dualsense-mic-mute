# DualSense Mic Mute для Windows

Кнопка **mute** на геймпаді DualSense від PS5 починає працювати у Windows так само, як на PS5:
натиснув — мікрофон вимкнено, **кнопка світиться помаранчевим**. Натиснув ще раз — мікрофон увімкнено, світло згасло.

[English version](README.md)

## Проблема

Підключаєш DualSense до комп'ютера з Windows, а кнопка мікрофона нічого корисного не робить:

- Windows не знає, навіщо ця кнопка.
- Steam Input і DS4Windows можуть призначити на неї клавішу, але **світлодіод не загоряється**, і не видно, вимкнено мікрофон чи ні.
- Програми, які вміють його вмикати, або ставлять драйвер віртуального геймпада (ViGEm), або платні.

## Що робить скрипт

Невеликий скрипт працює у фоні й:

1. Стежить за кнопкою mute (через USB і Bluetooth).
2. Вимикає мікрофон у Windows:
   - **через USB** — мікрофон самого геймпада, і всередині геймпада, і у Windows (`Headset Microphone (DualSense)`);
   - **через Bluetooth** — Windows не бачить мікрофон геймпада через Bluetooth, тому вимикається **мікрофон за замовчуванням** (наприклад, гарнітура).
3. Вмикає світлодіод на кнопці (мікрофон вимкнено) або гасить його (увімкнено).
4. Кожні 2 секунди повторює команду світлодіоду: Steam і деякі ігри її перебивають.

- Лише стандартна бібліотека Python. **Нічого не треба ставити через pip, жодних драйверів.**
- Геймпад не перехоплюється: ігри та Steam працюють як завжди.
- Сам підключається знову, якщо геймпад від'єднали чи вимкнули; стан mute зберігається.
- Після перезапуску скрипт знімає mute з мікрофона, який сам вимкнув, тож мікрофон не залишиться вимкненим назавжди.

## Що потрібно

- Windows 10 або 11
- Python 3.8 або новіший з [python.org](https://www.python.org/downloads/) (потрібен `pythonw.exe`, щоб працювати у фоні без вікна)
- DualSense або DualSense Edge, через USB-кабель (з передачею даних, не лише зарядний) або Bluetooth

## Встановлення

1. Завантаж репозиторій (**Code → Download ZIP**) і розпакуй у постійне місце, наприклад `C:\Tools\dualsense-mic-mute`.
2. Відкрий PowerShell у цій папці й запусти:

   ```powershell
   powershell -ExecutionPolicy Bypass -File install-autostart.ps1
   ```

   Скрипт додасть ярлик «DualSense Mute» в автозавантаження і одразу запуститься у фоні.
3. Натисни кнопку mute. Світлодіод має засвітитися помаранчевим.

## Як користуватися

| Що | Як |
|----|----|
| Перевірити наживо | зупинити фоновий скрипт (див. [Видалення](#видалення)), потім `python dualsense_mute.py --probe` і натискати кнопку |
| Увімкнути всі мікрофони й погасити світлодіод | `python dualsense_mute.py --release` (лише коли фоновий скрипт зупинено) |
| Журнал | `dualsense_mute.log` поруч зі скриптом (`MUTED` / `LIVE` на кожне натискання) |
| Поточний стан | `state.json` (`"muted": true/false`) |

Одночасно працює лише одна копія, друга сама закривається.

## Видалення

У папці зі скриптом запусти:

```powershell
powershell -ExecutionPolicy Bypass -File install-autostart.ps1 -Remove
```

Це зупинить скрипт, прибере його з автозавантаження, **увімкне мікрофон, який він вимкнув**, і погасить світлодіод.
Після цього просто видали папку. У системі нічого не залишається: ні записів у реєстрі, ні драйверів, ні служб.

## Якщо щось не так

| Симптом | Що перевірити |
|---------|---------------|
| Світлодіод не реагує | Відкрий `dualsense_mute.log`. Якщо немає рядка `DualSense connected over ...`, скрипт не запущено: знову запусти `install-autostart.ps1`. |
| Світлодіод горить, але тебе чути | Програма (Discord, OBS тощо) бере звук з іншого мікрофона. Через USB у ній має бути вибраний мікрофон DualSense, через Bluetooth — мікрофон за замовчуванням. |
| Через Bluetooth вимикається не той мікрофон | Кнопка вимикає мікрофон **за замовчуванням**: Параметри → Система → Звук → Вхід, вибери потрібний. |
| Windows перемкнула звук на `Speakers (DualSense)` | Параметри → Система → Звук → Вихід, поверни свої навушники. |
| У грі світлодіод блимає або гасне | Гра часто перезаписує світлодіод, скрипт повертає його за 2 секунди. |

## Як це влаштовано

Скрипт відкриває геймпад як звичайний HID-пристрій зі спільним доступом, тому нічого не ламає:

- читає вхідні звіти (USB `0x01`, Bluetooth `0x31`) і дивиться біт кнопки mute;
- надсилає вихідні звіти (USB `0x02`, Bluetooth `0x31` з CRC32), які вмикають світлодіод і вимикають мікрофон у самому геймпаді;
- вимикає мікрофон у Windows через інтерфейс Core Audio `IAudioEndpointVolume`.

Формат звітів узято з драйвера Linux [`hid-playstation`](https://github.com/torvalds/linux/blob/master/drivers/hid/hid-playstation.c).

## Де перевірено

- Windows 11, DualSense через Bluetooth і USB.
- DualSense Edge підтримується за кодом пристрою, але не перевірявся. Якщо перевіриш — напиши.
